部署失败

① 在服务器上启动

服务器包默认给 Unix（Linux / macOS）用。把下面命令贴到服务器终端执行：

curl -LO https://github.com/imginez/pubchat/releases/latest/download/PubChat_server.tar.gz mkdir -p pubchat-server && tar -xzf PubChat_server.tar.gz -C pubchat-server --strip-components=1 cd pubchat-server pip install websockets python src/hosts/server.py --port 8865

启动后会先问「服务器已有公网地址」：填你的反代域名（如 https://chat.example.com）并确认，终端就会打印一条认领链接——永久有效、只能用一次。

反代要把 /api/ 和 /claim 指到管理口（默认 8866），其余页面与 /ws 指到对外口。

② 填认领链接

认领页打开后按提示输入服务器终端显示的 6 位码，完成认领后就能以管理员身份进入。
