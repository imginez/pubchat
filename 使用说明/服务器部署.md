# 服务器部署

面向"一台有公网地址的机器，大家加入"的场景。只想在自己电脑上用，看 [安装包](../安装包/) 里的桌面端就够了。

## 本机单 exe（推荐给个人和小团队）

1. 装桌面端，打开一个窗口（四个页签：聊天 / 管理 / 我的 / 关于；成员管理在「管理」的二级页签里）。
2. 对外端口默认 `8765`（局域网可访问），管理口 `8766` 只绑 `127.0.0.1`。
3. 数据在 `%LOCALAPPDATA%\PubChat`；`--data-dir D:\chat` 可改。
4. 内置窗口依赖系统 WebView2（Win10/11 一般自带）；没有时自动回退 tkinter 控制台，也可手动 `--classic-gui`。

从源码跑：`pip install websockets qrcode pywebview` 然后 `python src/desktop.py`。

打包单 exe：`powershell -ExecutionPolicy Bypass -File src\packaging\build.ps1`（产物 `dist\PubChat.exe`，脚本结束打印 SHA256）。

## 服务器（一台有公网地址的机器，大家加入）

```bash
python src/hosts/server.py --port 8865 --admin-port 8866 --data-dir /srv/pubchat/data
```

- 首次启动终端打印 **一次性认领链接 + 6 位码**；链接默认永久有效（`BOOTSTRAP_TTL = 0`，设成秒数才有时限），打开 `…/claim#b=<token>` 输码换取长期设备凭证，**认领后链接立即失效**。
- 反代：`/api/` 与 `/claim` → `127.0.0.1:8866`，其余页面与 `/ws` → `8865`。
- **指向 8865 的 nginx location 必须加 `proxy_http_version 1.1;` 与 `proxy_set_header Connection "";`**，否则 HTTP/1.0 短连接会让上游提前断连，对外表现全是 502。
- **管理 API 强制要求 `X-Forwarded-Proto: https`**（nginx 写 `$scheme`），漏了会一律 403。
- 管理口永远不要直接对公网开放。

## 公网访问（可选，cloudflared）

下载 `cloudflared.exe` 放到 `PubChat.exe` 同目录，设置页三选一：

- **临时地址**：零配置，拿到 `https://xxxx.trycloudflare.com`，关掉即断、下次换域名——只适合临时验收。
- **固定域名**：Cloudflare Zero Trust 建隧道 → Public Hostname 指向 `http://localhost:8765` → 把隧道 Token 粘进 PubChat。Token 只写本机 `tunnel.json`，启动时用环境变量传给 cloudflared，不出现在进程命令行。
- **已有地址**：已有 nginx / Caddy / 其他隧道时填完整 `https://...`，程序只负责展示和二维码。

反代与页面**都不得下发 `X-Frame-Options` 或 `CSP frame-ancestors`**——桌面窗口用 iframe 装实例，加了就是白屏，这一条有冒烟用例锁着。

## 从旧版本迁数据

旧 `pubchat.db` 的账号、消息、Key 都能直接接管：向导里选「已有数据库？」上传，或 `PubChat.exe --import D:\old\pubchat.db`。

导入前校验表结构与用户数（不是 PubChat 库直接拒绝），现有库先备份成 `pubchat.db.bak-<时间>` 再原子替换，Key 与旧库完全一致。
